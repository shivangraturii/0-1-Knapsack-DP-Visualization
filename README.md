# 0/1 Knapsack using Dynamic Programming

## 📌 Project Description

This project implements the **0/1 Knapsack Problem** using the **Dynamic Programming (DP)** approach.

The program reads multiple test cases from an input text file, calculates the maximum possible value for each test case, displays a **live ASCII visualization of the DP table**, and stores the final results in `result.txt`.

---

## 🎯 Objective

The objective of the 0/1 Knapsack problem is to select items such that:

- The total weight does not exceed the knapsack capacity.
- The total value is maximized.
- Each item can either be selected once or not selected at all.

---

## 📂 Project Files

| File | Description |
|------|-------------|
| `knapsack.py` | Main Python program implementing the 0/1 Knapsack algorithm |
| `Knapsack data (2).txt` | Input file containing multiple test cases |
| `result.txt` | Stores the maximum value obtained for each test case |
